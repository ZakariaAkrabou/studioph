# StudioPH - Professional Photography Portfolio & Client Gallery Platform

![StudioPH Logo](https://via.placeholder.com/150x50?text=StudioPH)  
*Empowering Photographers with a Complete Portfolio and Client Gallery Solution*

## Overview

StudioPH is a comprehensive, self-hosted photography portfolio and client gallery management platform designed for professional photographers. Built with a one-time purchase model, it offers complete control over your photography business tools without recurring subscription fees.

## 🚀 Key Features

### 📸 Portfolio Management
- Create and organize stunning photography portfolios
- Categorize work by types (wedding, portraits, fashion, etc.)
- Responsive galleries that look great on all devices

### 🔒 Client Spaces
- Create private, password-protected galleries for clients
- Share curated collections with secure access keys
- Client-friendly interface for easy photo viewing and downloading

### 🎨 Admin Dashboard
- Intuitive interface for managing all your content
- Drag-and-drop image uploads with Cloudinary integration
- Real-time preview of changes

### 💼 Business Ready
- No monthly subscriptions - one-time purchase
- Complete data ownership and privacy
- Customizable branding to match your studio's identity

## 🛠 Tech Stack

### Frontend
- React 19 with Vite
- Redux Toolkit for state management
- TailwindCSS for styling
- React Router for navigation
- React Hot Toast for notifications

### Backend
- Node.js with Express.js
- MongoDB with Mongoose ODM
- JWT Authentication
- Cloudinary for image storage
- Multer for file uploads

## 📦 Installation

### Prerequisites
- Node.js 18+
- MongoDB 6.0+
- Cloudinary account (for image storage)

### Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/studioph.git
   cd studioph
   ```

2. Install dependencies for both frontend and backend:
   ```bash
   # Install backend dependencies
   cd backend
   npm install
   
   # Install frontend dependencies
   cd ../frontend
   npm install
   ```

3. Set up environment variables:
   - Copy `.env.example` to `.env` in both `backend` and `frontend` directories
   - Update with your configuration (MongoDB URI, Cloudinary credentials, JWT secret, etc.)

4. Start the development servers:
   ```bash
   # In backend directory
   npm run dev
   
   # In frontend directory (new terminal)
   cd frontend
   npm run dev
   ```

5. Access the application:
   - Admin Panel: `http://localhost:5173/admin`
   - Client Website: `http://localhost:5173`
